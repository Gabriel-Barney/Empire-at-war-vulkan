Alamo engine test build, 2026-11-07
====================================

How to run
----------
- Play.cmd       Forces of Corruption, no mod. Log: alamo_game_log.txt.
- Play_Mod.cmd   Any mod. Double-click it for a menu of every mod installed on this PC:
                 Steam workshop items (subscribed mods) and folders in corruption\Mods.
                   type a number      play that mod (Enter alone plays your last pick again)
                   C and a number     check a mod without playing: loads it the way the game does and
                                      opens a report (mod_check.txt): missing files, campaigns, scripts,
                                      shaders. Run this first if a mod will not start.
                   a+b (e.g. 7+1)     play mod a on top of mod b (a submod on the mod it needs).
                                      Submods whose modinfo.json names the mod they need are stacked on
                                      their own; the menu shows "(on top of 1)".
                   F                  a mod folder somewhere else
                 Or drag a mod folder (the one holding its Data folder) onto Play_Mod.cmd.
- In the game: the main menu's Mods button lists the same mods, checks the one you select and
  restarts the game with it.

Both launchers find the game through Steam on their own. If they cannot, they ask once for the
"corruption" folder and remember it in game_path.txt.

Each mod gets its own folder under mod_runs (named after the mod: ws<workshop id> or local_<folder>)
with its shader cache, its saves, log.txt and mod_check.txt, so mods never mix saves. Please send
that log.txt with any report. The first start of a mod builds its shader cache, so it is slower.
The base game keeps its saves in %LOCALAPPDATA%\alamo\Saves.

Built from: @BUILD@.

What to try
-----------
- Thrawn's Revenge (menu entry "Thrawn's Revenge 3.3, workshop 1125571106"): galactic conquest,
  skirmish land and space, save and load, as in the 2026-11-04 build.
- The other installed mods: Fall of the Republic, EAW-Remake, Age of Legends, and the local submods
  (Thrawn's Legacy HD, the ships transfer and compatibility patches). Check each with C<number>
  first; the report's last line says OK or ERRORS.
- The in-game Mods button: does the list match, does switching restart into the right mod?

Changes since test build 2026-11-04
-----------------------------------
- Mods in general, not only Thrawn's Revenge: no faction, unit, planet or map name is built into the
  engine any more; factions, AI players, skirmish starting forces, the skirmish planet and the default
  map come from the mod's data. Base Forces of Corruption plays as before.
- STEAMMOD=<id> works like the original (the launcher uses it for workshop mods); several mods can
  be stacked, the first one wins.
- Mod check report: missing files, Lua scripts that do not compile or fail, engine calls a mod uses
  that the port does not have yet, shader problems, and a hint when a submod is checked without the
  mod it needs.
- Mod shaders: shader model 3 effects are translated; Age of Legends and EAW-Remake show no shader
  issues in the check.
- Fixes found with EAW-Remake and Age of Legends: story files with their own root tag, planets made
  as variants of a template planet, a crash when a fighter attacked a whole group, Find_Nearest with
  no player.
- Galactic AI, battles and story: more of the original's AI budget and goal rules, fighter formations,
  landing and team behaviour, story victory rewards reaching the battle and the galaxy.
- Graphics options: named quality levels, one anti-aliasing control; Auto Detect picks a level
  from the GPU.

Known gaps
----------
- EAW-Remake: Single Player in its main menu does nothing yet (its menu draws Single Player as a
  heading); its space skirmish on Geonosis runs slowly (huge asteroid fields).
- Age of Legends: the skirmish setup's game-type list stops the skirmish start.
- Mods that ship shader sources (.fx) without compiled files (Thrawn's Revenge's AlamoEngine.fx,
  Fall of the Republic's terrain effect) draw those effects with the fallback, because this build
  does not compile .fx sources at run time yet; the check report lists them as shader warnings.
- Mods without a modinfo.json show their workshop id in the in-game Mods list (the Play_Mod.cmd
  menu knows the names of EAW-Remake and Age of Legends).
- Mods with 32-bit precompiled Lua scripts lose those scripts (the original 64-bit game has the
  same limit).
