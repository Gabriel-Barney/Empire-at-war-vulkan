# modc t04: names that must not appear as string literals in engine/ sim code (docs/MODS.md §1 rule 1, docs/status/modc-audit.md).
# One name per line, matched case-insensitively as a whole token inside a literal: the characters before and after
# the match must not be letters or digits ('_' and punctuation separate tokens), so "Rebel_Infantry_Squad" and
# "AI_Player_Underworld" match REBEL / UNDERWORLD, "BasicRebel" and "TEXT_FACTION_REBELLION" do not.
# A line starting with '=' is matched only against the whole literal (trimmed, any case): for names that are also
# common words or tag parts ("Is_Neutral", "no longer hostile").
# A literal that is 9 to 11 digits not starting with 0 (a Steam workshop item id) is always a violation.
# Allowed uses carry a marker comment (check_mod_names.py, docs/status/modc-audit.md).
