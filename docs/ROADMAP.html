      How sessions update this roadmap

      Every session and account updates the same files with roadmap_store.py write; this page is rebuilt from them. Each task has its own key, so changes to different tasks of one group merge cleanly. Full rules: docs/ROADMAP_PROTOCOL.md.

      python roadmap-store/roadmap_store.py write changes.json

changes.json is a list of {op, collection, doc_id, data}, op = set | update | delete:
update  items/<id>  {tasks:{t03:{s:"done"}}, updated:"2026-10-30", by:"<session name>"}
update  items/<id>  {tasks:{t09:{t:"New task", s:"todo", o:9}}, updated, by}     add a task
update  items/<id>  {status:"partly"}                                          group status
update  items/<id>  {after:["opt1","s7"]}     groups that must finish first
update  nodes/<ID>  {status:"done"}                                            box colour
set     items/<new-id>  {title, node, status, mod, order, after, tasks:{}, updated, by}   new group
set     log/<yyyymmdd-hhmmss-session>  {at:"<ISO time>", by:"<session name>", text:"what changed"}   one line per change
