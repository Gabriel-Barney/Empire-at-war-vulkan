## Elements read outside the descriptor tables (modc t25)

`RadarMap.xml` is read by `RadarMapClass` (loader 0x359390). The loader opens the file and hands the root
element to the recursive walker 0x3572c0. The walker checks no element path. At every level it upper-cases each
element name and compares it with the special names below. Every other element whose text is not empty goes to
`Parse_Database_Entry` 0x356bb0 with upper-cased text: a `TBD` value only logs a warning, and other values are
looked up in the RadarMapClass table (0xa39c50). An element with no text is skipped, and the walker always
descends into child elements. So `RadarMap`, `RadarMapEvents` and `RadarMapSettings` are not compared at all:
they are plain containers, the root name is not checked, and a known child is read at any depth. [H]
An unknown child with text logs "Unprocessed entry" and is ignored. [H]
The `name` attribute is read with the literal `name` (0x81db3c); whether that lookup ignores case is not
settled. [L]
