## Notable findings

- `config.meg` `.LUA` files are **compiled Lua 5.0 bytecode** (`\x1BLuaP`, 32-bit size_t/int, 8-byte lua_Number). `64Patch.meg` re-ships the **same 324 (FoC) / 260 (EaW) names as plain-text Lua source** (Perforce `$Id` headers), shadowing the bytecode. The merged extraction therefore contains Lua *source*.
- `shaders.meg` contains only compiled `.FXO` effects (D3D9 effect binaries, magic `01 09 FF FE` = fx_2_0); no `.FX` HLSL source ships in any archive. `Patch2.meg` overrides 3 FXOs.
- `Audio/SFX/*.meg` store **bare filenames** (no `DATA\AUDIO\SFX\` prefix); the audio system resolves SFX by leaf name against these archives.
- All other archive names are stored upper-case with `\` separators and a `DATA\` prefix.
